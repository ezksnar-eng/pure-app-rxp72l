٢لغة التطبيق ومصدره
شغّل السيرفر على 127.0.0.1 وهذا المنفذ (أو اقرأ os.environ["PORT"]). لا تستخدم debug=True.

اضغط أو اسحب ZIP مشروع Android Studio
جافا أو كوتلن أو C++ — لازم بيه settings.gradle
الموقع يبني مشروعك كما هو بدون ما يغيّر بيه شي (الاسم والأيقونة والحزمة من مشروعك). إذا مشروعك بيه gradlew ينستخدم، وإلا يستخدم Gradle 8.7.
حتى التحديث ينثبت فوق النسخة القديمة: الموقع يوقّع كل بناء بمفتاح ثابت ويرفع رقم الإصدار (versionCode) تلقائي.
التطبيق يفتح موقعك مباشرة، وأي تعديل تسويه على الموقع يبين بالتطبيق بدون ما تبني من جديد.

٣الإعدادات
ملء الشاشة الكامل (يخفي شريط الحالة وثقب الكاميرا ومنطقة البطارية فوق، وشريط التنقل تحت)

⚡ تعديل فوري (يتحدث بدون APK جديد)
ابنِ APK مرة وحدة، وبعدها أي تعديل تسويه اضغط «⚡ تحديث فوري» والتطبيق يتحدث لحاله عند كل واحد فاتحه. يحتاج مستودع عام، ويشمل الكود والملفات بس (مو الإعدادات والمكتبات).
🌐موقع يطلع بالبحث (اختياري)
ينشر نفس محتوى ZIP/الكود كموقع حقيقي بمستودع عام منفصل على GitHub Pages، برابط دائم تگدر تشاركه أو تسويله فهرسة بگوگل. غير مرتبط ببناء الـ APK.
قفل الاتجاه عمودي فقط
مستودع خاص على GitHub (ينطبق عند أول بناء)
🎯 جهّز نسخة لنشرها على Google Play (AAB)
يبني ملف AAB إضافي موقّع بمفتاح دائم يتولد أول مرة ويبقى نفسه بكل تحديث (شرط لنشر بگوگل بلي). يفعّل «مستودع خاص» تلقائي ويطفّي «تعديل فوري» — لأن مفتاح النشر لازم يبقى سري. باقي خطوات النشر (حساب المطوّر، معلومات المتجر) يدوية بالكونسول، موجودة بملف README-PLAY-AR.txt داخل المشروع.

بناء التطبيق

  • ⏺تجهيز مشروع الأندرويد
  • ⏺رفع المشروع إلى GitHub
  • ⏺بناء الـ APK بالسحابة
  • ⏺جاهز للتنزيل

🔗 ربط GitHub

GitHub يبني الـ APK لك بالسحابة مجاناً. مرة وحدة تربط، وبعدها كل تطبيقاتك تتبنى بضغطة.
  1. سوّي حساب مجاني بـ GitHub (إذا عندك حساب تخطّاها).
  2. افتح صفحة إنشاء التوكن، الصلاحيتين repo و workflow تنحطون تلقائي. نزّل لتحت واضغط Generate token.
  3. انسخ التوكن (يبدأ بـ ghp_) والصقه تحت.
التوكن ينحفظ على جهازك بس، وما ينرسل إلا لـ GitHub.
